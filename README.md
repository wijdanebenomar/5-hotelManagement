SYSTEME RÉSERVATION D’HÔTEL - BLUEWAVE



1\. Présentation du projet:



BlueWave est une application web de réservation d’hôtel développée en Java JSP/Servlet. Elle permet aux clients de consulter les chambres disponibles, créer un compte, se connecter, effectuer des réservations et gérer leurs informations personnelles. L’administrateur peut gérer les chambres, les services, les réservations et les paiements à travers un tableau de bord dédié.

**4. Prérequis d'installation**



Avant d'exécuter le projet, installer :



Java JDK 17 ou supérieur

Apache Tomcat 10

MySQL Server 8

NetBeans IDE

MySQL Connector/J



**5. Instructions de lancement:**



1. Cloner le dépôt GitHub.
2. Importer le projet dans NetBeans.
3. Créer la base de données MySQL.
4. Exécuter le script SQL disponible dans le dossier database.
5. Configurer les paramètres de connexion dans la classe DBConnection.
6. Démarrer Apache Tomcat.
7. Exécuter le projet depuis NetBeans.
8. Ouvrir l'application dans le navigateur.



**6. URL de déploiement**



Application exécutée localement via Apache Tomcat.



URL locale :



http://localhost:8080/hotel
